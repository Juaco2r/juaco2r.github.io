Cell Well Segmentation

Desktop GUI for immunofluorescence cell segmentation, cell-level feature extraction, Manders colocalization analysis, QuPath-compatible GeoJSON export and optional DICE/IoU validation against ground-truth annotations.

Python ≥ 3.9 PyQt5 GUI TIFF / OME-TIFF Watershed Manders DICE validation QuPath GeoJSON
Repository Zenodo DOI Back to tools

DOI: 10.5281/zenodo.20387083

What it does

Cell Well Segmentation implements a classical computer-vision workflow for low-density immunofluorescence cell images. It segments cell instances, extracts per-cell morphology and intensity features, calculates Manders colocalization metrics, exports QuPath-compatible GeoJSON annotations and can validate masks against a full-image ground-truth GeoJSON.

  • Single-image or bulk-image processing
  • ROI-based parameter exploration before full-image processing
  • Skip completed outputs or resume missing post-processing outputs
  • Optional DICE validation during parameter tuning and final processing

Input images

The application is designed for multi-channel immunofluorescence microscopy images, especially TIFF and OME-TIFF files.

Default channel convention

  • 0: nuclei channel, for example DAPI
  • 1: red marker channel
  • 2: green marker channel
  • 3: cytoplasmic/cell channel used for cell foreground

Channel mapping can be adjusted from the Custom parameters panel.

Segmentation workflow

  1. Read the selected microscopy image and preserve channel structure when possible.
  2. Create RGB and CellCyto composites.
  3. Smooth the nuclear channel and detect local maxima as cell seeds.
  4. Estimate foreground from the cytoplasmic/cell channel using Otsu-based thresholding.
  5. Run marker-controlled watershed segmentation.
  6. Filter segmented instances by object area.
  7. Export instance masks, feature tables, Manders metrics, GeoJSON and previews.

Feature extraction

For each accepted segmented cell, the software exports morphology, centroid and channel intensity measurements. The main feature table is saved as cell_features.csv.

  • label: instance identifier
  • area_px and perimeter_px
  • centroid_y and centroid_x
  • Red, green and blue max, mean, median, std, p25 and p75
  • red_total, green_total, blue_total
  • red_cv, green_cv, blue_cv
  • red_positive, green_positive and double_positive as 0/1 biological positivity flags

Biological positivity flags

The positivity columns are not segmentation thresholds. They classify segmented cells after feature extraction using the user-defined biological red and green thresholds. 

red_positive = red_mean ≥ biological_red_threshold
green_positive = green_mean ≥ biological_green_threshold
double_positive = red_positive AND green_positive

They are exported as 0/1 values to make filtering easier in Excel, R or Python.

Manders colocalization

Manders coefficients are calculated per cell to quantify asymmetric overlap between the red and green marker signals. The output is saved in manders_features.csv and merged into cell_features_with_manders.csv.

  • manders_global_red_in_green: fraction of red signal located in green-positive pixels using global thresholds.
  • manders_global_green_in_red: fraction of green signal located in red-positive pixels using global thresholds.
  • manders_cellotsu_red_in_green and manders_cellotsu_green_in_red: same calculation using per-cell Otsu thresholds.
  • manders_biological_red_in_green and manders_biological_green_in_red: same calculation using user-defined biological thresholds.

The two directions are expected to differ because Manders coefficients are asymmetric: red-in-green and green-in-red measure different biological overlap relationships.

DICE / validation

Cell Well Segmentation can compare the predicted binary cell mask against a full-image ground-truth GeoJSON annotation. During Parameter Exploration, the selected ROI is matched to the corresponding region of the full-image GeoJSON, allowing parameter tuning with DICE, IoU, precision and recall.

  • Uses QuPath-style full-image GeoJSON coordinates.
  • Rasterizes the relevant annotation region to the same mask size.
  • Reports pixel-level DICE, IoU, precision and recall.
  • Optional final validation outputs are saved under validation/.

Main outputs

  • RGB.tif: RGB composite used for feature extraction
  • CellCyto.tif: composite used for segmentation
  • instances.tif: instance segmentation mask
  • cell_features.csv: cell-level measurements and positivity flags
  • manders_features.csv: cell-level Manders metrics
  • cell_features_with_manders.csv: merged feature table
  • manders_summary.json: thresholds and summary metadata
  • qupath_final.geojson: QuPath-compatible cell annotations
  • preview.png: visual quality-control summary
  • validation/: optional DICE/IoU reports and masks

Notes & limitations

  • Best suited for low-density or moderately separated cells.
  • Highly confluent or strongly overlapping cells may require parameter tuning.
  • No machine-learning or deep-learning model is required.
  • Ground-truth GeoJSON validation assumes the annotation uses the same image coordinates and resolution.
  • Large images may require sufficient RAM because full-image processing reads image data into memory.
