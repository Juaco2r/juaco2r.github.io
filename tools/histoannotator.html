Overview

HistoAnnotator is a web and Android application for interactive annotation of histology and microscopy images. It is designed for research workflows involving whole-slide images, standard raster images, scientific multichannel fluorescence TIFF files and QuPath-compatible GeoJSON annotations.

The application combines browser-based and Android tablet use with local-first annotation storage, allowing downloaded images and annotations to remain available when a continuous server connection is not present.

Key features

  • OpenSlide-based whole-slide viewing with Deep Zoom / OpenSeadragon navigation
  • Freehand, Brush, Polygon, Rectangle, Circle and Wand tools
  • Multi-object selection with merge, intersection and subtraction operations
  • Annotation classes, colors and undo / redo
  • QuPath-compatible GeoJSON import and export
  • GeoJSON sharing from Android
  • Local-first annotation storage and offline-friendly image viewing

Multichannel fluorescence

Supported scientific fluorescence TIFF files can be visualized without flattening the source data to RGB first. Display controls are non-destructive and do not alter raw scientific pixel values.

  • Independent channel visibility
  • False-color assignment
  • Automatic display-range estimation
  • Per-channel minimum and maximum display values
  • Gamma and brightness controls
  • Persistent display settings per image

Typical use cases

  • Manual annotation of histology and microscopy images
  • Review and editing of QuPath-compatible annotations
  • Tablet-based annotation workflows
  • Exploration of multichannel fluorescence images

Project status

HistoAnnotator is currently distributed as pre-release research software for development and testing. It is not clinically validated medical software and should be deployed according to institutional data-governance, security and ethics requirements.

Current scope

  • Web application and Android tablet interface
  • Whole-slide and raster image annotation
  • QuPath interoperability through GeoJSON
  • Offline-friendly cached image and annotation workflows
  • Research-oriented multichannel fluorescence visualization
